## 简介

在 BCI 系统中，我们面临的根本挑战是：**观测是带噪声的，而决策需要的是真实的隐状态（latent state）**。

举例来说，EEG 信号 $y$ 包含了注意力、情绪、运动意图等信息，但我们真正想知道的是被试脑中正在发生的、导致这些信号产生的**内在认知状态** $z$。这个 $z$ 无法直接观测，只能通过含噪的 $y$ 去推断。

一旦估计出隐状态，下游任务——比如决策——就能建立在更可靠的信号之上。

---

## HMM：最简单的例子

隐状态建模最经典的框架是**隐马尔可夫模型（Hidden Markov Model, HMM）**。

HMM 的核心假设：

- **$z_t$ 是离散的隐状态**，来自有限集合 $\{1, 2, ..., N\}$
- **$y_t$ 是对 $z_t$ 的观测**，可以是离散的，也可以是连续的
- 状态转移 $z_{t+1} \sim p(z_{t+1} \mid z_t)$ 是Markov链
- 观测概率 $y_t \sim p(y_t \mid z_t)$ 描述了隐状态如何"投射"为可观测信号

```
z_t --> z_{t+1} --> z_{t+2} --> ...
|       |          |
v       v          v
y_t    y_{t+1}    y_{t+2}
```

在 BCI 场景下，$z_t$ 可以代表"放松"、"运动想象"、"注意力集中"等认知模式，而 $y_t$ 就是 EEG/EMG/ fNIRS 等生理信号。

**但 HMM 有一个关键局限：$z_t$ 必须是离散的**。

现实中，大脑的认知状态往往是连续、高维的——注意力有强度之分，情绪有维度空间。把连续的认知状态强行量化为几个类别，是对信息的严重压缩。

---

## State-space Model：连续的隐状态

为了突破这个局限，**State-space Model（状态空间模型，SSM）** 将隐状态推广为连续变量。

SSM 由两个核心方程描述：

### 观测方程（Observation Equation）

$$ y_t = g(x_t, u_t, v_t) $$

- $x_t$：$t$ 时刻的**隐状态**（连续向量）
- $u_t$：**系统输入**（可选择，如刺激呈现）
- $v_t$：**观测噪声**，反映了测量过程的不确定性（EEG 采集、传感器噪声等）
- $y_t$：实际观测到的信号

### 动态方程（Dynamic Equation / State Transition）

$$ x_{t+1} = f(x_t, u_t, w_t) $$

- $x_{t+1}$：下一时刻的隐状态
- $u_t$：系统输入
- $w_t$：**过程噪声**，反映了隐状态自身的不确定性（认知过程的随机性）

> 两个方程都带有噪声——这正是现实世界的本质：**观测永远是带噪的，状态转移也不是完全确定的**。

与 HMM 的离散 $z_t$ 不同，SSM 中的 $x_t$ 可以是任意维度的连续变量。认知过程不再被强制压缩为几个类别，而是以连续的向量形式在状态空间中演化。

---

## 闭环智能：从 SSM 到 POMDP

在 Open-loop BCI 中，系统采集信号 → 估计状态 → 分类/解码，就结束了。

在 **Closed-loop Intelligence（闭环智能）** 场景下，系统不仅需要估计当前状态，还需要**基于这个状态做出决策并施加干预**——而干预效果又会通过下一轮观测反馈回来。

这时，经典 SSM 就不够用了，需要引入 **POMDP（Partially Observable Markov Decision Process）** 框架。

### POMDP 的核心要素

| 要素 | 含义 |
|------|------|
| 隐状态 $x_t$ | 无法直接观测的真实状态（与 SSM 相同） |
| 观测 $y_t$ | 部分可观测的信号 |
| **信念状态（Belief State）$b_t$** | **核心区别**：对隐状态的概率分布 $b_t(x) = p(x_t \mid y_{1:t}, u_{1:t-1})$ |
| 动作 $a_t$ | 系统基于 $b_t$ 采取的行动 |
| 奖励 $r_t$ | 动作带来的反馈 |
| 状态转移 | $x_{t+1} \sim p(x_{t+1} \mid x_t, a_t)$ |

### 信念状态与 Bayesian Filtering

POMDP 的核心创新是引入了 **信念状态 $b_t$** ——不是点估计，而是一个后验分布。

信念更新（Bayesian Filtering）：

$$ b_{t+1}(x_{t+1}) = \eta \cdot p(y_{t+1} \mid x_{t+1}) \sum_{x_t} p(x_{t+1} \mid x_t, a_t) b_t(x_t) $$

即：

1. **预测（Predict）**：基于当前信念 $b_t$ 和动作 $a_t$，预测下一时刻隐状态的先验分布
2. **更新（Update）**：接收到新观测 $y_{t+1}$ 后，用贝叶斯法则更新后验分布得到 $b_{t+1}$

$$ \underbrace{b_t}_{\text{prior}} + \underbrace{y_t}_{\text{observation}} \rightarrow \underbrace{b_{t+1}}_{\text{posterior}} \xrightarrow{a_t} \underbrace{r_t}_{\text{reward}} $$

有了信念状态，决策模块就不再基于不确定的点估计行动，而是基于**完整的概率分布**做出最优或近似最优的决策。

---

## 小结

| 框架 | 隐状态 | 关键特点 |
|------|--------|----------|
| HMM | 离散 | 状态转移链 + 观测发射概率 |
| SSM | 连续 | 观测方程 + 动态方程，双重噪声 |
| POMDP | 连续 + **信念状态** | Bayesian Filtering + 动作/奖励闭环 |

这三层递进关系构成了从**感知**到**决策**的完整认知建模链条：

```
HMM (离散分类) → SSM (连续状态估计) → POMDP (信念决策)
     估计"是什么"     估计"怎么样"         决定"做什么"
```
